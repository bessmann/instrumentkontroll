This is the website [instrumentkontroll.se](https://instrumentkontroll.se/) — a single-page static site for Instrumentkontroll Bessmann AB.

## Tech Stack

The site is a single static page generated by [Hugo](https://gohugo.io/). Hugo ships as one self-contained Go binary — there is **no npm / `node_modules`** — which keeps the build simple, fast, and free of the npm supply-chain attack surface. To work on the site you'll need [Hugo installed](https://gohugo.io/installation/) (extended edition, matching the `HUGO_VERSION` pinned in `netlify.toml`).

**Build & styling**
- [Hugo](https://gohugo.io/) (extended) — static site generator
- [Open Props](https://open-props.style/) — design tokens (CSS custom properties), vendored locally under `static/css/` rather than loaded from a CDN
- [Andy Bell's Modern CSS Reset](https://andy-bell.co.uk/a-modern-css-reset/) — baseline reset
- [Google Fonts](https://fonts.google.com/) — IBM Plex Sans / Sans Condensed / Mono
- A few lines of vanilla JavaScript (`static/js/menu.js`) drive the mobile menu — no JS framework

**External services** (loaded in the browser at runtime)
- [Web3Forms](https://web3forms.com/) — contact-form backend + hCaptcha
- [GoatCounter](https://www.goatcounter.com/) — privacy-friendly analytics
- Google Maps embed — location map

**Hosting**
- [Netlify](https://www.netlify.com/) — build settings live in `netlify.toml`

### Design principles
- Somewhat future-proof
- Low size
- Easy to maintain
- Adding or editing content should be easy
- Low cost (preferably free)

## 🧞 Commands

All commands are run from the root of the project, from a terminal:

| Command              | Action                                            |
| :------------------- | :------------------------------------------------ |
| `hugo server`        | Starts local dev server at `localhost:1313`       |
| `hugo --gc --minify` | Builds the production site to `./public/`         |
| `hugo --help`        | Get help using the Hugo CLI                       |
